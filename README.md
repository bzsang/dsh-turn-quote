# dsh-turn-quote（引用上文）

**中文** | [English](README.en.md)

[![开放插件市场](https://img.shields.io/endpoint?url=https://dshopen.org/badge/dsh-turn-quote.json)](https://dshopen.org/zh/plugins/dsh-turn-quote/) [![awesome · DSH plugin](https://awesome-dsh-plugin.com/badge.svg)](https://awesome-dsh-plugin.com/p/bzsang/dsh-turn-quote/) ![license](https://img.shields.io/badge/license-MIT-2563eb) ![DSH](https://img.shields.io/badge/DSH-%3E%3D0.2.1--rc.5%20%3C0.3.0-2F6FED)

把**本次会话前文**引用到正在写的消息里。对话跑偏时，把当初那句需求（或当时的结论）@ 回来，让模型以原文为准继续，不用手动复制粘贴。

| 你能做的 | 菜单里的样子 |
| --- | --- |
| 引用**一条**消息（我 / 助手） | `第3轮·我`、`第3轮·助手` |
| 引用**一整轮问答**（提问 + 回答） | `第3轮·问答` |
| 一次引用**最近多轮**问答 | `最近2轮`、`最近3轮`、`最近5轮` |
| 按**正文内容搜索**再引用 | `@` 后直接打字，显示命中数与命中处上下文 |

选中后，草稿里只留下一个小标签（如 `@最近3轮`）；发送时标签自动展开成引用块，把原文附进这条消息。

## 安装

```sh
dsh plugin --profile <你的 profile> add https://github.com/bzsang/dsh-turn-quote
```

- 当前版本：**0.2.0**（纯 JavaScript，无构建步骤）
- 要求：DeepSeek Harness `>=0.2.1-rc.5 <0.3.0`（0.2.2-rc.1 实测可用）
- 尚未发布 npm 包，从 GitHub 安装即可；装完重启该 profile
- 也可以在 **插件 → 发现** 的「Open Plugin Market」索引里搜 `引用上文` / `turn quote` 安装

## 用法

1. 在输入框敲 `@`，菜单里会出现三个分组：

   - **对话上文** —— 单条消息，按时间倒序
   - **整轮问答** —— 一整轮的提问与回答
   - **最近多轮** —— 连续多轮的问答

   也可以点输入框左侧的 `“` 按钮，等同于在光标处输入 `@`。

2. **搜索**：`@` 后继续输入即可过滤，支持三种写法：

   | 输入 | 效果 |
   | --- | --- |
   | `@白屏` | 在正文里搜「白屏」，描述显示 `命中 1 处 · …上下文…` |
   | `@3` / `@第3轮` | 只看第 3 轮 |
   | `@我` / `@助手`（或 `@you` / `@assistant`） | 只看某个说话人 |

3. 选中后草稿里只留小标签，光标停在标签后，可以接着写新问题；连续 @ 多次可以叠加多个引用。

4. 发送时展开成引用块。整轮问答：

```
【引用上文 · 第3轮 · 问答】
我：白屏了，点项目看板没反应
助手：是提前 return 导致的 hooks 顺序问题，已修复并补了冒烟测试。
【/引用上文】
```

多轮：

```
【引用上文 · 最近3轮（第2–4轮）】
我：第二轮：再加批量操作，支持改状态和负责人
助手：第二轮回答：批量栏已加，执行后逐条写回，失败会带错误原因。
……
【/引用上文】
```

## 常见问题

**Q：和「引用选中文字」类插件有什么区别？**
A：那类要你先手动选中一段文字；本插件按**轮次**引用——不用选，而且能把整轮问答或最近几轮一起带上。

**Q：会修改/删除我的对话历史吗？**
A：不会。插件只**读取**已加载的对话内容，把它附进你正在写的这条消息；不发请求、不写文件、不回退任何历史。

**Q：为什么有的旧对话搜不到？**
A：只覆盖**当前会话已加载**的历史（会话窗口里的内容）。很久远、尚未加载进窗口的消息不会出现在列表里。

**Q：引用内容太长会怎样？**
A：单条引用最多保留 4000 字，超出部分会注明"已省略 N 字"；多轮引用按顺序分配这 4000 字预算。

**Q：`@"..."` 还能用吗？**
A：能。`@"..."` 是 DSH 官方的路径引用语法，本插件不插手引号形式的搜索。

**Q：怎么卸载？**
A：`plugin_manager` 里移除 `dsh-turn-quote`，或 `dsh plugin --profile <profile> remove dsh-turn-quote`。

**Q：为什么不发 npm 包？**
A：不是必须。两个市场都支持"公开仓库 + 固定提交"安装。发 npm 的好处是会进入 Awesome 的 DSH 索引（该索引只收 npm 包）、显示下载量、并让市场自动跟随新版本。

## 与其他插件的区别

对着市场索引查过同类，三类近邻都不是同一件事：

| 同类 | 例子 | 与本插件的区别 |
| --- | --- | --- |
| 扩展 `@` 菜单的引用来源 | `dsh-reference-anything`、`dsh-expert` | 引用的是**别的会话 / 别的 AI 的历史**或专家名册；本插件引用的是**本次会话自己的前文** |
| 把**选中的文字/代码**变成引用 | `dsh-client-ui-quote`、`dsh-cherry-quote`、`dsh-quote-reply`、`@kialajin/dsh-quote-selection` | 要先手动选中一段；本插件按**轮次**引用，不用选 |
| 会话回退 / 重发 | `dsh-session-rewind`、`@anionex/dsh-turn-rewind`、`@jochenyang/dsh-rewind-plugin` | 回退会把那一轮**从对话里撤回/删除**；本插件**不删任何东西**，只把原文附进当前这条消息 |

一句话：**按轮次引用，而不是按选中文字；是引用，不是回退。**

## 实现

浏览器端插件，Host 侧只有一个空的 `apply`（无工具、无服务、不写会话事件）：

- 用 `ctx.inputTriggers.registerSource()` 注册一个 `@` 触发源，与官方 `@文件` / `@会话` 同菜单共存；
- 选中项走官方 chip 通道（`slash/input-insert-reference`），撤销栈、草稿持久化、复制形态都是原生行为；
- 发送时由 chip 的 `codec.serialize()` 展开成引用块；
- 候选数据来自 Session Controller 已加载的事件窗口（`sessions.binding(id).eventSource`），无新增 RPC；
- 只收录真人输入（`source.kind === "user"`）与带文字的助手消息，系统上下文、技能目录、注入信息不会出现在菜单里。

## 安全

- 无网络请求、不上传任何数据；读到的对话内容只写回你自己的输入框和消息。
- 插件以完整权限运行第三方代码；本包不调用系统命令、不读写工作区文件。
